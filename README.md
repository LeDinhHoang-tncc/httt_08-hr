
# HR Recruitment System

Website quản lý tuyển dụng nhân sự, tích hợp API trích xuất dữ liệu từ CV và hỗ trợ chấm điểm ứng viên.

## Công nghệ dự kiến

- Frontend: React
- Backend: Python
- Database: PostgreSQL
- Version Control: Git và GitHub

## Chức năng chính

- Quản lý tài khoản và phân quyền.
- Quản lý tin tuyển dụng.
- Ứng viên tải CV và ứng tuyển.
- Tích hợp API trích xuất thông tin CV.
- Phân tích và chấm điểm CV theo yêu cầu công việc.
- Nhà tuyển dụng xem, đánh giá và cập nhật trạng thái hồ sơ.

## Cấu trúc dự án

- `backend/`: xử lý nghiệp vụ và API.
- `frontend/`: giao diện người dùng.
- `docs/`: tài liệu thiết kế và báo cáo.
